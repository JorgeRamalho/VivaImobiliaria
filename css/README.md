# css/

Folhas de estilo em camadas (P3).

| Arquivo | Papel |
|---------|--------|
| `style.css` | Entry — `@import` de tokens → base → components |
| `tokens.css` | Design tokens (`:root`) |
| `base.css` | Reset, tipografia, botões, skip-link, reduced-motion |
| `components.css` | Header, hero, cards, forms, footer, media queries |

O HTML aponta para `css/style.css` (raiz do site).
